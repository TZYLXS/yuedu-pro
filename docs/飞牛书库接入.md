# 接入飞牛（fnOS）书库

装好本 APK 后，可以让它直接读飞牛上的 [FnReader](https://github.com/TZYLXS/FnReader) 书架 / 书源 / 缓存，
不需要在每一台设备上都重新导入一堆书源。

原理：不在 APK 里写死接口，而是由 FnReader 生成一份 **Legado 书源**，
把「搜索 / 详情 / 目录 / 正文」四个动作映射到 FnReader 的 `/api/m/*`。

## 一、在飞牛上取链接

1. 打开飞牛桌面上的「阅读」（FnReader）→ 设置
2. 找到「阅读 APK 接入」区块（1.7.1 起提供）
3. 复制 **「书源导入链接」**，形如：

```
legado://import/bookSource?src=http%3A%2F%2F<飞牛IP>%2Fapp%2Flegado-web%2Fapi%2Fm%2Fbooksource%3Ftoken%3D<令牌>
```

也可以只要「书源 JSON」地址，在 App 里粘贴同样的地址。

> 令牌来自「设置 → 手机接入」，重置令牌后书源要重新导入。

## 二、在 APK 里导入

1. 手机 / 平板与飞牛同一网段（能打开飞牛网页即可）
2. 阅读 → 我的 → 书源管理 → 右上角菜单 → **网络导入** → 粘贴链接
3. 导入成功后书源列表出现「飞牛书库」
4. 书架 → 搜索 → 选「飞牛」分组，即可搜到飞牛上已配置书源里的书

## 三、接口对应（便于排障）

| 阅读里的动作 | 实际请求 |
| --- | --- |
| 搜索 | `GET /api/m/legado/search?key=&page=` |
| 详情 | `GET /api/m/legado/book?u=<b64url(bookUrl)>&s=<b64url(书源)>&n=<书名>` |
| 目录 | `GET /api/m/legado/toc?u=<b64url(bookUrl)>` |
| 正文 | `GET /api/m/content?url=<bookUrl>&index=<i>` |
| 封面 | `GET /api/m/cover?url=<bookUrl>` |

书源规则（服务端生成，APK 侧零改动）：

```json
{
  "ruleSearch":   {"bookList":"$.books[*]","name":"$.name","author":"$.author","bookUrl":"$.bookUrl","coverUrl":"$.coverUrl","kind":"$.kind","introduce":"$.intro","lastChapter":"$.lastChapter"},
  "ruleBookInfo": {"name":"$.book.name","author":"$.book.author","coverUrl":"$.book.coverUrl","kind":"$.book.kind","introduce":"$.book.intro","lastChapter":"$.book.lastChapter","tocUrl":"$.book.tocUrl"},
  "ruleToc":      {"chapterList":"$.chapters[*]","chapterName":"$.title","chapterUrl":"$.url"},
  "ruleContent":  {"content":"$.paragraphs[*]"}
}
```

## 四、常见问题

| 现象 | 处理 |
| --- | --- |
| 导入提示「格式错误」 | 链接里 `src=` 后面必须整段 URL 编码，直接复制设置页的链接，别手拼 |
| 搜索没结果 | 先在电脑端确认书源能搜到；飞牛只会用 `enabled && checkStatus=ok` 的源 |
| 打开书提示「书源不存在」 | 书源被删了，回阅读重新搜索 |
| 打开书提示「不在书架中」 | 用的是旧书签；回搜索重新点开一次会自动入架 |
| 封面空白 | 封面走 `/api/m/cover` 代理，源站防盗链时留空，不影响阅读 |

## 五、面板九项功能（服务端 FnReader 1.11.x）

| 项 | 作用 |
| --- | --- |
| ① 导入书源 | 下 `/api/m/sources.json` 一次性导入，之后搜索 / 目录 / 正文都走飞牛 |
| ② 全部同步到飞牛书架 | 本机书架全量比对：新书建进书架（`origin` 填书源真实地址）、进度回传、缺封面补推 |
| ③ 打开飞牛阅读网页 | 直接跳飞牛网页端 |
| ④ 测试连接 | 探 `/api/m/info`，回显服务端版本 |
| ⑤ 拉取书架 | 把飞牛书架拉到本机 |
| ⑥ 上传进度 | 只回传阅读进度 |
| ⑦ 保存设置 | 存地址与令牌 |
| ⑧ 上传本机缓存 | 按 §16 把 `.nb` 原文 + 图片 + 封面推到 `/api/m/cache`，网页端离线可读 |
| ⑨ 书源双向同步 | 按 §17 用 `lastUpdateTime` 做 LWW，本机改动推上去、服务端更进的版本覆盖本地 |

后台还有一个「手机解析桥」前台服务：连着服务器时长轮询 `/api/m/remote/pending`，
执行 `search` / `toc` / `content` / `rank` 四类任务并回 `POST /api/m/remote/result`。
其中 `rank` 是 1.9 新增——服务端抓起点榜单被反爬时，让你这台手机代抓并回结构化榜单。
